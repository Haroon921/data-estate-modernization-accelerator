## Partner workshop: Data Estate Modernization (1 day)

Start the session with the [Data Estate Modernization Accelerator overview](data-estate-modernization-overview.pptx). A [PNG preview](assets/data-estate-modernization-overview.png) is also available for invitations and internal communications.

| Block | Content | Lab |
|---|---|---|
| 1. Why now (45m) | SQL end of support/renewal, Synapse->Fabric momentum, AI-ready data | - |
| 2. Assess (60m) | Inventory scripts, Azure Migrate/DMA, reading results | Lab 1: run assessment on sample estate |
| 3. Decide (45m) | Decision matrix, "when not to", router | Lab 2: route the sample inventory |
| 4. Business case (60m) | Calculator, Hybrid Benefit, capacity sizing | Lab 3: build a customer case |
| 5. Migrate (90m) | Landing zone, runbooks, cutover | Lab 4: deploy Bicep, migrate a sample DB |
| 6. Validate (30m) | Reconciliation, baselines | Lab 5: run reconcile.py |
| 7. Modernize (60m) | Mirroring, medallion, Purview, AI | Lab 6: mirror + Gold table + semantic model |
| 8. Sell it (30m) | Discovery questions, objections, packaging offers | Role play |

**Success metrics to track**: partners trained, assessments run, deals influenced, savings identified, time-to-first-migration.
