# Support

## Questions and ideas

- Use a GitHub Discussion for architecture questions, implementation experiences, and general ideas when Discussions are enabled.
- Use the feature request issue template for a concrete enhancement.
- Use the bug report template for reproducible defects.

Search existing issues before creating a new one and remove all customer data, credentials, connection strings, and tenant-specific identifiers.

## Product support

This community accelerator is not an official Microsoft support channel. For Azure or Microsoft Fabric product incidents, billing issues, quota requests, or service-specific support, use the support process associated with your Azure subscription or Microsoft support agreement.

## Security

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).
